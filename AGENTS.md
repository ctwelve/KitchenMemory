## Agent skills

### Issue tracker

Issues are tracked in GitHub Issues. See `docs/agents/issue-tracker.md`.

### Triage labels

The canonical default triage labels are used unchanged. See `docs/agents/triage-labels.md`.

### Domain docs

Before changing domain concepts, architecture, or product behavior, read the relevant development docs and decisions. See `docs/agents/domain.md`.

### Xcode testing

Run native application and UI tests through Xcode so it manages test-runner signing. Before connecting to Xcode or troubleshooting test execution, read [the Xcode agent workflow](docs/agents/xcode.md).
