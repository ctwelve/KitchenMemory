# Security Policy

## Supported versions

Kitchen Memory is under active development. There is no formal version support
schedule yet. Security fixes are prioritized for the current development
version and the latest published release when practical; older releases may not
receive fixes.

## Reporting a vulnerability

Please report suspected security vulnerabilities privately. If GitHub provides
the **Report a vulnerability** option on the
[Kitchen Memory Security tab](https://github.com/ctwelve/KitchenMemory/security),
use that private reporting channel. If it is unavailable, contact the repository
owner using the contact information published on their GitHub profile and
request a private channel. Do not send sensitive details until that channel is
established, and do not open a public issue, discussion, or pull request for an
unpatched vulnerability.

Include the affected version or commit, the impact, and steps to reproduce when
you can do so safely. Avoid sending real recipes, account credentials, or other
personal data. The maintainers will acknowledge reports as soon as practical,
investigate them, and coordinate any disclosure with the reporter. No response
time or outcome is guaranteed.
