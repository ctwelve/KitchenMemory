Kitchen Memory 0.3.0 expands the personal Recipe Library alpha. This release
is available for macOS; iPhone/iPad distribution and TestFlight remain deferred.

## Changes

- Organize Recipes with Folders and Tags, including combined library filters.
- Preserve saved Recipe history and recovery evidence as the library changes.
- Store Recipe image payloads privately alongside synchronized library content.
- Use English (United States or United Kingdom), Canadian French, Mexican
  Spanish, German, or Italian, with localized bundled Recipe packs.
- Improve the library, editor, Session, Settings, and startup-recovery structure,
  with bounded native accessibility checks and a fresh Mac ordinary-use pass.
- Include the reviewed dependency notices and privacy manifests in the signed
  application, with consolidated engineering and contributor documentation.

## Alpha limits

The interface and storage contract remain provisional. Alpha data is disposable:
keep original copies of anything that matters. The project will deliberately
reset alpha cloud storage and stabilize the data contract before beta.

The comprehensive VoiceOver, keyboard, device, language/layout, and stabilized
workflow matrix remains beta work. iCloud delivery has no immediate-delivery
promise. The recorded foreground-delivery timeout is inconclusive; separate
reconnection and relaunch checks passed, and the maintainer accepted that limit.

The download is a Developer ID-signed, notarized universal Mac app, version
0.3.0 (418), for macOS 26 or later. The verified ZIP and checksum are available
from the [GitHub release](https://github.com/ctwelve/KitchenMemory/releases/tag/release/0.3.0).
The [publication record](release-publication-0.3.md) preserves artifact validation.
