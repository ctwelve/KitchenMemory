This nonshipping probe explicitly uses `SystemLanguageModel.default` and three fictional text samples. It reads no application data and does not use a remote model. On a compatible Mac with Apple Intelligence available, run `swift probe.swift`. The captured output is one exploratory run, not a benchmark or a reproducibility promise for generated wording. See the [research record](../privacy-preserving-ai-assistance.md) for the interpretation and limitations.
